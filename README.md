# 🐍 Snake Water Gun Game

A simple Python-based Snake Water Gun game where the player competes against the computer.

## 🎮 About the Game

Snake Water Gun is a game similar to Rock Paper Scissors.

- 🐍 Snake beats 💧 Water
- 💧 Water beats 🔫 Gun
- 🔫 Gun beats 🐍 Snake
- Same choice → Draw

The computer randomly selects one option, and the player's choice is compared with the computer's choice to determine the result.

## 🛠️ Technologies Used

- Python
- Random Module
- Conditional Statements
- Loops
- User Input

## ✨ Features

- Player vs Computer
- Random computer choice
- Win/Lose/Draw result
- Simple command-line interface
- Beginner-friendly Python project
